# Release notes template

Copy for each GitHub release. Short, field-first, both languages. Credit the person whose
report caused a change — that is what makes people report again.

```markdown
## Field Mission Planner X.Y.Z

![what changed](link-to-gif-or-screenshot)

**What's new in the field**
- <one line: what the operator can now do> — thanks @<who reported it> (#<issue>)

**Fixed**
- <symptom as the operator saw it> (#<issue>)

**Download** — APK below · web version updates by itself:
https://tecelskyyivan-alt.github.io/ardu-field-planner/

---

**Що нового в полі**
- <рядок: що оператор тепер може> — дякую @<хто повідомив> (#<issue>)

**Виправлено**
- <симптом, як його бачив оператор> (#<issue>)

APK — нижче · веб-версія оновлюється сама.
```

After publishing: one post in Discussions → Announcements, same text.
